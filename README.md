# Average Sensor Readings

## Project Purpose
This project calculates statistics of sensor readings using Python.

## Sensor Readings
[22, 24, 26, 28, 30]

## Results
- Count = 5
- Minimum = 22
- Maximum = 30
- Average = 26.0

## How to Run
1. Open the Python file.
2. Run the code using Python.
3. View the output.

## Python Functions
- len() counts readings.
- min() finds the minimum.
- max() finds the maximum.
- sum() calculates the total.
